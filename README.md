# 🎡 幸运抽奖 / 幸运抽人

一个纯前端的班级活动小工具，包含两个页面：

- **抽奖模式**：马卡龙配色大转盘，点击中心按钮旋转，指针指到哪就是哪个奖品。
- **抽人模式**：名字高速滚动，点「停止」后逐渐减速定格，撒花 + 音效揭晓幸运儿；支持按班级切换、不重复抽取、已抽名单记录。

无需后端、无需联网、无需安装依赖，所有库都在本地 `lib/` 目录里。

---

## ✨ 功能

**抽奖模式（`抽奖.html`）**

- 转盘扇形数量随奖品数量自动变化，配色自动循环
- 缓动旋转 5 秒停稳，弹出中奖提示
- 导入 / 拖拽 `.txt` 名单覆盖奖品

**抽人模式（`抽人.html`）**

- 名字高速滚动，停止时按「老虎机」方式逐渐减速定格
- 顶部胶囊按钮按班级（分组）切换，每个班独立记录已抽名单
- 「不重复抽取」开关，抽完会提示重置
- 空格键 = 开始 / 停止，适合投影大屏操作
- 中奖撒花（Canvas 粒子）+ WebAudio 合成音效（无音频文件）
- 名字长度自动适配字号，长名字不会溢出

## 🚀 快速开始

### 方式一：双击 `启动.bat`（Windows，推荐）

1. 双击 `启动.bat`，它会启动一个只监听本机的静态服务，并自动打开抽奖页面；
2. 服务器跑在标题为 `LotteryServer` 的最小化窗口中，关掉它即可停止；
3. 重复双击不会堆叠多个服务——脚本会先自动结束上一个再启动新的。

> 需要本机安装 Python 3（`python` 命令可用）。若没有安装，脚本会提示并直接打开文件夹。

### 方式二：自己起一个静态服务器

```bash
cd 项目目录

# 任选其一
python -m http.server 8777
npx serve .
```

然后浏览器访问 `http://127.0.0.1:8777/抽奖.html` 或 `http://127.0.0.1:8777/抽人.html`。

### 方式三：直接双击 html

能打开、也能抽，但浏览器会禁止网页读取同目录的 `.txt`（安全限制），此时程序会自动退回读取 `.js` 里的配置，或者你可以把 `.txt` 直接**拖进页面**手动导入。

## 📝 自定义内容

### 奖品

编辑根目录的 `奖品.txt`，一行一个：

```
棒棒糖
精美笔记本
免写作业券
```

### 名单（按班级分组）

1. 在 `名单/` 目录下按 `班级名.txt` 命名放好文件，例如 `名单/1班.txt`、`名单/2班.txt`；
2. 打开 `src/person.js`，把班级列表改成你的目录名（**必须与文件名前缀一致**）：

```js
const CLASS_LIST = ["1", "2", "3", "4"];
```

程序启动时会并发生成顶部切换按钮，默认选中列表里的第一个；每个班独立记录已抽名单。

> 任何一个班级文件读取失败时，会自动退回「单名单模式」：读取根目录的 `人名.txt`，此时切换按钮隐藏。

### 备用配置（无 txt 时使用）

- `奖品.txt` 读不到 → `src/奖品.js` 里的 `window.defaultPrizes`
- `人名.txt` 读不到 → `src/人名.js` 里的 `window.defaultNames`

两者都支持反引号字符串（一行一项）或数组写法：

```js
window.defaultPrizes = ["一等奖", "二等奖", "三等奖"];
```

### 手动导入

两个页面都支持点击「📁 导入名单」或把 `.txt` 直接拖到页面任意位置，导入的名单会临时覆盖当前数据（抽人页会作为额外的「导入名单」分组存在，不影响原有班级数据）。

## ⚠️ 注意事项

- `.gitignore` 默认排除了 `名单/*.txt` 和 `人名.txt`（里面有学生真实姓名），克隆下来请自己新建这些文件；如果只是自己用，本地放好即可；
- 所有 `.txt` 请保存为 **UTF-8** 编码（Windows 11 记事本默认即 UTF-8），否则中文会乱码；
- `.bat` 文件内部保持纯英文/符号：cmd 按 GBK 解析脚本，混入中文可能导致乱码或路径错误；
- 项目不上传任何数据、不发起外部请求，名单只存在你本地；
- 页面路径含中文，若用命令行工具访问需要做 URL 编码（浏览器地址栏直接输入中文即可）。

## 🛠 技术说明

- 原生 JavaScript + Canvas，无构建步骤、无框架
- 转盘：Canvas 2D 绘制扇形 + GSAP 旋转缓动
- 抽人：`setTimeout` 递归调度实现变速滚动（加速 → 减速 → 定格）
- 音效：WebAudio API 实时合成，不依赖音频文件
- 撒花：Canvas 粒子系统
- 弹窗：SweetAlert2

仅用于教学、班级活动等场景，可自由修改使用。
